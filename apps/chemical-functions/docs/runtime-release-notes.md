# Approved chemical workbench runtime

This asset packages the catalog and trained model from the maintainer's working local application. It contains the SQLite snapshot, model bundle, and original model run manifest. It does not contain the complete source dataset or all research/preparation outputs.

The committed `runtime/lock.json` records the archive and file SHA-256 hashes. Source attribution and chemical acceptance policies remain in the application repository. Model scores rank recorded functional-use annotations and are not experimentally validated probabilities of industrial usefulness.

Use this asset with its matching source commit and dependency contract. Runtime packages should be produced only from the trusted local preparation/training workflow.
