# Licensing status and provenance

No software license is applied by this folder package. MIT was proposed for the project's own code; the maintainer still needs to select an actual license and its scope before describing the project as open source. A multi-app repo may license its shared pipeline separately from individual applications.

The pinned CPDat v4.0/version-5 Figshare API metadata was checked and declares CC0:

- Dataset: https://epa.figshare.com/articles/dataset/The_Chemical_and_Products_Database_CPDat_MySQL_Data_File/5352997/5
- Version metadata: https://api.figshare.com/v2/articles/5352997/versions/5
- Declared license: https://creativecommons.org/publicdomain/zero/1.0/

That declaration describes the pinned CPDat deposit. It is not a blanket license determination for every separately collected dashboard export, third-party source document, dependency, or downstream artifact. Preserve original source notices and provenance. Do not apply a project code license over third-party materials.

The generated model is trained locally, rather than downloaded pretrained weights. Its training-data provenance, feature/dependency contract, and release manifest remain distinct from the project's software-license choice.

Dependencies and container components retain their own licenses. This package has not performed a complete dependency/license audit. Preserve bundled notices when redistributing images and review their software inventories in the release pipeline.
